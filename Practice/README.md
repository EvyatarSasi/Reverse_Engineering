# Additional Assembly Practice

Small x86 assembly exercises kept separately from the assignment submissions. Their exact assignment membership is not established by the available files.

| Source | Topic |
| --- | --- |
| [ex2.asm](ex2.asm) | Memory addressing and register access |
| [if_ex3.asm](if_ex3.asm) | Comparing and swapping two input values |
| [ex4.asm](ex4.asm) | Testing whether an input value is even or odd |
| [ex5.asm](ex5.asm) | Nested loops and numeric output |
| [ex6.asm](ex6.asm) | Calling a routine that clears registers |
| [beale.asm](beale.asm) | Decoding a string with XOR |
| [endien.asm](endien.asm) | Reversing the byte order of a value |
| [tmp.asm](tmp.asm) | Minimal scratch program |

The `.exe` files are existing compiled artifacts. `training.inc` is a course helper used by several sources. These exercises use FASM syntax and require its Windows include environment; sources and executables have not been rebuilt or runtime-verified during repository organization.
